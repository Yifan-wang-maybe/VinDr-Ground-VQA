# Protocol details for the reproducibility appendix (item #10)
Extracted from the evaluation code and run records. Drop-in facts; phrasing is the author's choice.

- **Precision:** all scoring in bfloat16 (`torch.bfloat16`), eager attention, logits cast to float32 before softmax/log-odds readout.
- **Prompt forms (state explicitly — two are in use):** the core occlusion tables (Fig. 1 / Tables 4, 11, 12 and the resize experiment) score the *bare question*; the accuracy gate, FPR experiments, and all robustness re-runs (fills, placement) append " Please answer with yes or no." Each experiment is internally consistent; margins are not comparable *across* the two prompt forms (Δ ≈ 3.5 nats median on full images).
- **Yes/No margin:** log p(first-token "Yes") − log p(first-token "No") from a single forward; token ids from each model's own tokenizer (`tokenizer("Yes"/"No", add_special_tokens=False)[0]`).
- **Random-box draws:** rejection sampling, size-matched to the ROI, IoU < 0.05 with the ROI and (in the evidence-avoiding variant) with *every* annotated finding box on the image; **seed = case index, identical across models** — paired comparisons stay paired. Main tables use **one draw per case**; the resize experiment (Table 5) uses **k = 5 draws averaged**; a k = 5 vs k = 20 sensitivity check is reported separately.
- **Fills:** default = per-image mean color; robustness appendix = Gaussian blur (radius = max(6 px, 0.15 × box max-side), applied to the region from a whole-image blur) and black. Placement robustness = body-restricted (region mean intensity above the image's 25th percentile) and ROI-intensity-matched (|Δmean| ≤ 25/255) draws.
- **Image preprocessing:** VinDr DICOMs → windowed PNGs (VOI-LUT, MONOCHROME1 inverted, longest side 1024). Normalized boxes are mapped to the *PNG* pixel grid; each model's own processor then handles resizing (MedGemma fixed 259 vision tokens; Lingshu median 1,112; Qwen3-VL median 866 [802–1,026]; InternVL3.5 median 3,331 — measured on 20 test images; see vision-token table).
- **Blind condition:** the conversation is built with *no image entry at all* (not a blank image); all four chat templates accept text-only turns. (Qwen3-VL's 83% blind yes-rate in §5.5 is under this construction.)
- **Case selection:** release *test* split; presence-positives shuffled with `random.Random(0)`; the first n taken. The val split was carved from official train at image level with seed 0 (`finalize_release.py`); the official VinDr test split is untouched.
- **Enhancement layer provenance:** generated 2026-08-10/12 by `claude-fable-5` (prompts in `fable5_qa.py` / `fable5_pass.py`): question paraphrases, `answer_nl` natural locations, `roi_appropriate`/`roi_reason` box audit (image crops with the box drawn were sent for the audit — see DUA discussion). Analytical use of generated fields: `roi_appropriate` in the §5.3 stratification, and `answer_nl` as the reference for the judged localization metric. All other analyses use only deterministic fields.
- **Hard-set thresholds:** correlated pool = pairwise lift ≥ 1.5 with ≥ 30 co-occurrences (lift computed on all 18,000 images' annotations); unrelated pool = lift ≤ 0.90; caps 200/pair (correlated), 60/pair sampled at eval.
- **"3.33 findings per abnormal image":** mean over the 5,471 box-annotated images of the full VinDr-CXR annotation release.
- **Bootstrap convention:** median [95% CI], paired bootstrap over cases, 10,000 resamples, seed 0; proportions via Wilson. Pre-registered tests: one-sided sign test for excess > 0 per tertile; large-vs-small tertile difference; isolated-vs-correlated via unpaired bootstrap plus the area×confidence-stratified re-slice.
